# 04 打包与隐私清理

## 给别人分发

应发送构建生成的 `wechat-rpa-portable-v1.2.zip`。不要把自己已经配置和运行过的整个文件夹手动压缩，也不要把 CipherTalk 安装程序重新加入 ZIP。

公开清理版 ZIP 不包含：

- `config/app.json`
- `config/secrets.dat`
- `state/`
- `logs/`
- `data/wechat_messages.xlsx`
- `data/ciphertalk-cache/`
- CipherTalk 配置数据库及其备份
- 微信数据库、缓存、媒体文件
- Excel 运行数据及 `.before_` 备份
- `CipherTalk-*-Setup.exe`

接收者运行 `1-安装密语.exe` 时，才会从 CipherTalk 官方 Release 下载安装程序并核验 SHA-256。下载后的文件属于接收者本机数据，已被 `.gitignore` 和构建脚本排除。

## 重新生成清理包

开发者更新文件后运行：

```powershell
python runtime\build_release.py
```

脚本在临时目录构建并执行两类检查：

1. 排除配置、密钥、状态、日志、Excel、数据库、缓存和第三方安装程序。
2. 扫描真实格式 wxid、已填写密钥和个人绝对路径。

任一检查失败都不会生成 Release ZIP。发布前仍应查看 ZIP 文件列表并核对 `SHA256SUMS.txt`。

## 接收者要做什么

每位接收者必须自行安装依赖、登录本人微信、运行自己的 `setup.exe` 并填写自己的路径、wxid 和密钥。

任何人的 `secrets.dat` 都不应成为“预配置模板”；它绑定创建它的 Windows 登录用户，也不应传播。

## GitHub 发布要求

- 只从未运行过采集流程的干净仓库构建。
- 开启 Secret scanning、Push protection 和 Private vulnerability reporting。
- 不在公开 Issue 中接收密钥、聊天内容、真实 wxid 或日志原文。
- 如果敏感内容进入过 Git 历史或 Release，应视为已泄露，立即轮换凭据并清理完整历史。
