# 04 打包与隐私清理

## 给别人分发

应直接发送项目输出目录中的 `wechat-rpa-portable-v1.0.zip`。这个 ZIP 由清理脚本创建，不要把自己已经配置和运行过的整个文件夹手动压缩。

清理版 ZIP 不包含：

- `config/app.json`
- `config/secrets.dat`
- `state/collector_state.json`
- `state/new_messages.json`
- `logs/`
- `data/wechat_messages.xlsx`
- CipherTalk 配置数据库及其备份
- 微信数据库、缓存、媒体文件
- Excel 运行数据及 `.before_` 备份

## 重新生成清理包

开发者需要更新文件后，可运行：

```powershell
python runtime\build_release.py
```

脚本使用临时目录构建、检查禁止文件，并输出新的 ZIP。发送前仍建议查看 ZIP 文件列表，确认只有模板、程序、模块和文档。

## 接收者要做什么

每位接收者必须自行：

1. 安装依赖并登录自己的微信。
2. 解压 ZIP。
3. 运行自己的 `setup.exe`。
4. 输入自己的路径、wxid 和密钥。
5. 重启 CipherTalk，运行 `doctor.exe`。
6. 在自己的影刀流程中导入 `module1.py`。

任何人的 `secrets.dat` 都不应成为“预配置模板”；它绑定创建它的 Windows 登录用户，也不应传播。
