# 01 安装依赖

## 必需软件

1. Windows 10/11，使用拥有微信数据访问权限的同一 Windows 用户运行全部软件。
2. 微信桌面版：先正常登录，确认微信数据目录存在。
3. CipherTalk 最新桌面版或最新版源码：先启动一次，使 `%APPDATA%\ciphertalk\ciphertalk-config.db` 被创建。
4. 影刀客户端：建议使用与制作流程相同或更新的版本。
5. Microsoft Excel 桌面版（推荐但非强制）：存在时优先使用 Excel COM；没有时模块自动改用影刀 Python 自带的 openpyxl。WPS 正在打开目标文件时仍可能产生文件锁。

如果 CipherTalk 使用源码的 `start-dev.bat`，还需要其项目要求的 Node.js 环境。已安装的桌面版 `CipherTalk.exe` 不依赖此包内的 Node.js。

## 不随包分发的软件

本包不会复制或重打包微信、Excel、影刀、Node.js、CipherTalk，也不会复制任何人的微信数据库或 CipherTalk 配置数据库。请由每位用户从合法来源自行安装。影刀 Python 需要具备 `openpyxl` 和 `Pillow`；当前常见影刀版本已自带。

## 目录要求

- 将 ZIP 完整解压后使用，不能直接在压缩包内运行。
- 建议路径简短且长期固定，例如 `D:\WechatRpaPortable`。
- 配置后如果移动目录，重新运行 `setup.exe`，以更新影刀定位文件。
- Excel 目标文件不要放在会产生并发锁的网络盘；本地磁盘最稳定。
