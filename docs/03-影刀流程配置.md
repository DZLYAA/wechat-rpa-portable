# 03 影刀流程配置

## 导入自定义模块

1. 在新建的影刀流程副本中打开“自定义模块/代码模块”。
2. 新建或替换 `module1`，完整粘贴 `shadowbot\module1.py`。
3. 模块必须保留函数 `main(args=None)`，不要删除最后的 `return result`。
4. “调用模块”指令选择：模块 `module1`，函数 `main`。
5. 参数传空字典 `{}`，不要传字符串。返回结果保存为 `invoke_result`。

## 推荐主流程

把以下指令全部放入同一个“无限循环”内部：

1. 运行程序：`collect_silent.exe`。程序路径可直接浏览选择，不需要命令参数和工作目录。
2. 等待 3 秒。电脑较慢时改为 5 秒。
3. 调用 `module1.main`，参数 `{}`，返回 `invoke_result`。
4. 设置四个变量，类型都选“通用/任意”或让影刀自动识别：
   - `parse_ok = invoke_result["parse_ok"]`
   - `excel_saved = invoke_result["excel_saved"]`
   - `message_count = invoke_result["message_count"]`
   - `parse_error = invoke_result["parse_error"]`
5. 条件：`excel_saved == True` 时运行 `ack_silent.exe`。只有此分支可以 ACK。
6. 条件：`parse_ok == False` 或 `excel_saved == False` 时，把 `parse_error` 写入影刀日志，但不要执行 ACK。
7. 等待轮询间隔，默认 5 秒，然后回到循环开头。

循环外只放一次性启动或初始化动作；`collect -> 调用模块 -> 判断保存 -> ACK -> 等待` 必须整体处于循环内部。

## 返回变量类型

- `parse_ok`：布尔。
- `excel_saved`：布尔。
- `message_count`：数字/整数。
- `parse_error`：文本。
- `invoke_result`：字典/对象/通用，不要选择文本。

如果出现 `'str' object does not support item assignment`，说明调用模块时把参数传成了字符串。改成空字典 `{}`，或不传参数；新版模块也会尝试兼容 JSON 字符串，但仍建议使用字典。

## 图片和 Excel 注意事项

- 流程运行时尽量关闭目标 Excel，避免只读或文件锁。
- 安装 Microsoft Excel 时优先通过 COM 写入；未注册 Excel COM 时自动改用 openpyxl，流程无需更改。
- 图片成功解密且本地文件仍存在时，会嵌入第 8 列，并在第 9 列加入“打开原文件”链接。
- 图片文件被微信清理、CipherTalk 未暴露媒体路径或密钥缺失时，消息仍会写入，但预览可能为空。
- Excel 保存失败时 pending 不会清空，解除占用后下一轮会重试；消息键会避免重复行。
