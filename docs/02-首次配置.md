# 02 首次配置

## 运行配置工具

双击包根目录的 `setup.exe`。如安全软件询问，请核对文件来自你收到的原始 ZIP 后再决定是否允许运行。

依次填写：

1. **CipherTalk 目录**：桌面版所在目录，或源码项目根目录。
2. **CipherTalk 启动文件/命令**：桌面版选 `CipherTalk.exe`；源码版选 `start-dev.bat`。留空时工具会在根目录尝试自动寻找这两个文件。
3. **CipherTalk 配置数据库**：通常是 `%APPDATA%\ciphertalk\ciphertalk-config.db`。
4. **微信数据目录**：例如微信设置中显示的当前账号数据目录；必须选择包含数据库文件的账号目录。
5. **wxid**：当前微信账号的内部 wxid。
6. **Excel 保存路径**：建议保留包内默认位置，或选择本机固定目录下的 `.xlsx` 文件。
7. **数据库密钥**：64 位十六进制字符。
8. **图片 XOR/AES 密钥**：有则填写，没有可留空；缺失可能导致图片路径或预览不可用。
9. **轮询间隔**：建议 5 秒，不建议低于 2 秒。
10. **每次消息上限**：建议 200；若单个间隔可能产生大量消息，可适当提高。

点击“保存并初始化”。配置工具会先在 CipherTalk 配置数据库同目录的 `wechat-rpa-backups` 中创建备份，再写入当前账号配置。

## 配置文件说明

- `config/app.json`：本机路径、wxid 和运行参数，不含密钥。
- `config/secrets.dat`：三种密钥的 Windows DPAPI 加密文件，仅当前 Windows 用户可解密。
- `%LOCALAPPDATA%\WechatRpaPortable\install.json`：仅记录便携包目录，供影刀模块自动定位。

不要手动把密钥写入 `app.json`，不要把 `secrets.dat` 发给别人，也不要在截图、日志或聊天中暴露密钥。为了让 CipherTalk 解密数据库，配置工具还会按 CipherTalk 自己的配置格式把密钥写入其本机配置数据库；因此应保护 Windows 账号和 `%APPDATA%\ciphertalk` 目录，不要把该数据库发给他人。

## 验证

1. 完全退出并重新启动 CipherTalk。
2. 双击 `doctor.exe`。
3. `ciphertalkMcp` 通过说明本地会话接口可用。
4. 如失败，先确认 CipherTalk 已启动且 MCP 已启用，再核对数据库目录、密钥和 wxid。

首次执行采集只建立当前会话基线，新增数量为 0 是正常行为。基线完成后发送一条测试消息，再运行下一轮。
