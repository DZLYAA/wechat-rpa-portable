# 00 先安装密语 CipherTalk

如果电脑尚未安装 CipherTalk，请运行包根目录的 `1-安装密语.exe`。

公开工具包不内附 CipherTalk 安装程序。该入口会：

1. 显示 CipherTalk 的 CC BY-NC-SA 4.0 非商业许可提示。
2. 经用户确认后，从 CipherTalk 官方 GitHub Release 下载 v2026.729.0。
3. 计算 SHA-256，并与工具中固定的官方发布值比较。
4. 仅在校验成功后打开官方原版安装向导。

官方下载地址：

```text
https://github.com/ILoveBingLu/CipherTalk/releases/download/v2026.729.0/CipherTalk-2026.729.0-Setup.exe
```

固定 SHA-256：

```text
48354069b274591a2ca855fee8100addde3b0f75d05e8336ebb509f6a94bf88b
```

安装完成后必须启动一次 CipherTalk，使 `%APPDATA%\ciphertalk\ciphertalk-config.db` 被创建。随后退出 CipherTalk，运行本包的 `setup.exe` 填写当前用户的微信目录、wxid 和密钥。

如果电脑已经安装同版或更新版 CipherTalk，可以跳过安装，不要降级。配置工具会尝试自动识别安装位置；识别失败时手动选择 `CipherTalk.exe`。

官方安装程序没有 Windows Authenticode 数字签名。请核对来源和哈希，并遵守本机或组织安全策略。版本、来源及许可证详见 `vendor\ciphertalk` 目录。
