# 00 先安装密语 CipherTalk

如果电脑尚未安装 CipherTalk，请先运行包根目录的 `1-安装密语.exe`。

该入口会：

1. 查找内附的 CipherTalk v2026.729.0 官方 Windows 安装程序。
2. 计算 SHA-256，并与 GitHub Release 公布值比较。
3. 显示 CC BY-NC-SA 4.0 非商业许可提示。
4. 经用户确认后，打开官方原版安装向导。

它不会静默安装、不会跳过官方安装界面，也不会修改官方安装程序。

安装完成后必须启动一次 CipherTalk，使 `%APPDATA%\ciphertalk\ciphertalk-config.db` 被创建。随后退出 CipherTalk，运行本包的 `setup.exe` 填写当前用户的微信目录、wxid 和密钥。

如果电脑已经安装同版或更新版 CipherTalk，可以跳过安装，不要降级。配置工具会尝试自动识别安装位置；识别失败时手动选择 `CipherTalk.exe`。

版本、来源、哈希及许可证详见 `vendor\ciphertalk` 目录。
